# AI 도구 활용 가이드 — 논문 작성을 위한 스터디

논문을 쓰는 학생이 Git, Cursor, OpenCode, Sisyphus, Claude를 100% 활용할 수 있도록 가르치기 위한 교육 자료.

## 목적

AI 도구에 익숙하지 않은 학생이 논문 작성 과정(자료 조사 → 초고 작성 → 퇴고 → 버전 관리)에서 이 도구들을 자연스럽게 사용할 수 있도록 안내한다.

## 대상

- 논문 작성이 처음이거나, AI 도구를 논문에 활용해본 적 없는 학생
- 프로그래밍 경험이 없어도 따라갈 수 있는 수준으로 구성

## 도구 관계도

```
┌───────────────────────────────────────────────┐
│  Git (버전 관리)                                │
│  └── 논문 원고의 변경 이력 추적 & 협업           │
│                                               │
│  Cursor (편집기)                                │
│  ├── AI Chat — 질문, 자료 요약, 문장 다듬기      │
│  ├── Composer — 긴 글 구조 잡기 & 대규모 편집    │
│  └── Terminal                                 │
│       └── OpenCode (CLI)                      │
│            └── Sisyphus (에이전트)              │
│                 ├── 자료 조사 (Explore, Librarian)│
│                 ├── 구조 상담 (Oracle, Metis)    │
│                 └── 작업 위임 (Task Delegation)  │
│                      └── Claude (AI 모델)       │
└───────────────────────────────────────────────┘
```

## 문서 구조

```
docs/

├── 5_sisyphus/      # Sisyphus 에이전트 활용법
```

## 학습 순서

폴더 번호 순서대로 진행한다. 각 단계는 이전 단계의 이해를 전제로 한다.

1. **Git** — 파일 관리 습관부터 (모든 작업의 기반)
2. **Claude** — AI에게 좋은 질문을 하는 법 (도구 쓰기 전에 프롬프팅부터)
3. **Cursor** — 편집기에서 Claude 활용하기
4. **OpenCode** — 터미널 기반 고급 AI 도구
5. **Sisyphus** — 에이전트에게 작업 위임하기
6. **Workflows** — 전체 도구를 엮은 논문 작성 실전
