# AI 도구 활용 가이드 — 논문 작성을 위한 스터디

논문을 쓰는 학생이 Git, Cursor, OpenCode, Sisyphus, Claude를 100% 활용할 수 있도록 가르치기 위한 교육 자료.

## 목적

AI 도구에 익숙하지 않은 학생이 논문 작성 과정(자료 조사 → 초고 작성 → 퇴고 → 버전 관리)에서 이 도구들을 자연스럽게 사용할 수 있도록 안내한다.

## 대상

- 논문 작성이 처음이거나, AI 도구를 논문에 활용해본 적 없는 학생
- 프로그래밍 경험이 없어도 따라갈 수 있는 수준으로 구성

## 도구 관계도

```
┌───────────────────────────────────────────────┐
│  Git (버전 관리)                                │
│  └── 논문 원고의 변경 이력 추적 & 협업           │
│                                               │
│  Cursor (편집기)                                │
│  ├── AI Chat — 질문, 자료 요약, 문장 다듬기      │
│  ├── Composer — 긴 글 구조 잡기 & 대규모 편집    │
│  └── Terminal                                 │
│       └── OpenCode (CLI)                      │
│            └── Sisyphus (에이전트)              │
│                 ├── 자료 조사 (Explore, Librarian)│
│                 ├── 구조 상담 (Oracle, Metis)    │
│                 └── 작업 위임 (Task Delegation)  │
│                      └── Claude (AI 모델)       │
└───────────────────────────────────────────────┘
```

## 학습 순서

폴더 번호는 문서 정리용 번호이고, **AI 에이전트를 기본으로 사용하는 학습 흐름**은 아래 순서를 권장한다.

- **초급**
  1. **Cursor** — AI가 들어 있는 작업 환경부터 익힌다
  2. **Git** — Cursor 안에서 쓰게 될 버전 관리 습관을 배운다
  3. **Claude** — 더 좋은 결과를 얻기 위한 프롬프팅 원리를 정리한다
  - 목표: AI와 함께 논문 초고를 쓰고 수정하는 기본 작업 흐름을 만든다
- **중급**
  4. **OpenCode** — 터미널 기반 AI 작업 방식으로 확장한다
  5. **Sisyphus** — 에이전트에게 조사와 분석을 위임한다
  6. **Workflows** — 전체 도구를 실제 논문 작업 순서에 맞게 엮는다
  - 목표: 조사, 분석, 수정 작업을 더 체계적으로 자동화한다
- **고급**
  7. **LaTeX** — 제출용 형식과 조판까지 다루는 고급 과정
  - 목표: 제출용 형식, 참고문헌, 조판까지 포함한 완성형 작성 흐름으로 확장한다
