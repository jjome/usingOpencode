# Workflows — 도구를 실제로 어떻게 엮는가

이 문서는 각 도구의 기능을 다시 설명하기보다, 왜 여러 도구를 함께 써야 하는지와 실제 논문 작업에서 어떤 역할 분담이 생기는지 정리하는 데 초점을 둔다.

## 한 줄 요약

**논문 작업에서는 도구 하나를 깊게 아는 것보다, 상황에 따라 어떤 도구를 꺼내야 하는지 아는 편이 더 중요하다.**

## 이 폴더에서 다루는 방향

- 기능 설명보다 역할 분담 설명
- 이론보다 실제 작업 순서 중심
- 초급 사용자가 전체 그림을 잡는 데 도움을 주는 방향

## 먼저 다루면 좋은 것

- [ ] Cursor, OpenCode, Claude, Git을 왜 같이 쓰는지
- [ ] 초안 작성 단계에서 어떤 도구가 편한지
- [ ] 큰 수정이나 정리 작업에서 어떤 도구가 편한지
- [ ] Git이 왜 마지막 안전장치가 되는지
- [ ] 제출 단계에서 LaTeX가 왜 따로 필요한지

## 이 문서에서 특히 다루고 싶은 것

- [ ] 도구별 역할 분담표
- [ ] 논문 작성 단계별 추천 조합
- [ ] "이럴 때는 이 도구" 식의 선택 기준
- [ ] 초급 사용자가 과하게 복잡한 흐름에 빠지지 않는 방법

## 메모

> 학습하면서 발견한 팁을 여기에 추가
