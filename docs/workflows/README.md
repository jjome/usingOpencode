# Workflows — 논문 작성 실전 워크플로우

개별 도구를 익힌 뒤, 실제 논문 작성 과정에서 어떻게 조합하는지 정리한다.

## 다룰 주제

### 논문 작성 단계별 워크플로우
- [ ] 주제 선정 & 리서치 질문 잡기 (Claude 상담)
- [ ] 선행 연구 조사 (Librarian + Claude)
- [ ] 논문 구조 설계 (Oracle 상담 → Cursor에서 아웃라인 작성)
- [ ] 초고 작성 (Cursor + Claude Chat)
- [ ] 퇴고 & 피드백 반영 (Git 브랜치 + Cursor Composer)
- [ ] 최종 검수 (맞춤법, 인용, 형식 통일)

### 버전 관리 습관
- [ ] 의미 있는 단위로 커밋하기 (예: "서론 초안 완성", "2장 피드백 반영")
- [ ] 지도교수 리뷰 전후 브랜치 분리
- [ ] GitHub로 백업 & 공유

### 도구 선택 기준
- [ ] 간단한 질문 → Cursor Chat
- [ ] 깊은 조사/분석 → OpenCode + Sisyphus
- [ ] 대규모 글 수정 → Cursor Composer
- [ ] 버전 비교/되돌리기 → Git
