# LaTeX — 논문 작성 고급 과정

Markdown과 Git으로 초고를 다루는 데 익숙해졌다면, 이제 제출용 형식과 정교한 조판을 위해 LaTeX를 다룰 수 있다.

## 왜 고급 과정인가?

LaTeX는 강력하지만 초심자에게는 진입 장벽이 있다.

- 문서 구조를 코드처럼 관리해야 한다
- 빌드 과정과 에러 메시지에 익숙해져야 한다
- 학회/학교 템플릿을 다뤄야 하는 경우가 많다

그래도 논문 제출 단계에서는 매우 강력하다.

- 수식 작성이 편하다
- 참고문헌 관리가 체계적이다
- 표, 그림, 목차, 번호 체계가 안정적이다
- Git과 궁합이 좋다 (`.tex`, `.bib`가 모두 텍스트 파일이기 때문)

## 다룰 주제

### 시작하기
- [ ] LaTeX란 무엇인가

- [ ] `main.tex`와 장별 파일 분리

- [ ] 그림, 표, 부록 폴더 구성
- [ ] 템플릿 읽는 법

### Git과 함께 쓰기

- [ ] 의미 있는 단위로 커밋하기
- [ ] Markdown 초고에서 LaTeX로 옮기는 방법
