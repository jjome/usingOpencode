# LaTeX — 왜 나중에 쓰는가

이 문서는 LaTeX 문법을 깊게 가르치기보다, 왜 이 도구가 논문 제출 단계에서 도움이 되는지와 언제 도입하는 것이 좋은지 설명하는 데 초점을 둔다.

## 한 줄 요약

**LaTeX는 처음부터 꼭 필요한 도구는 아니지만, 제출용 형식과 참고문헌, 수식, 조판을 안정적으로 정리할 때 큰 도움을 준다.**

## 이 폴더에서 다루는 방향

- 문법 설명보다 도입 이유 설명
- 기능 목록보다 실제 장점 설명
- 초급 사용자가 겁먹지 않도록 사용 시점 중심

## 먼저 다루면 좋은 것

- [ ] 왜 Markdown만으로 끝나지 않는 경우가 있는지
- [ ] LaTeX가 제출 단계에서 주는 장점
- [ ] 템플릿 기반 작업이 왜 편한지
- [ ] Git과 같이 쓸 때 왜 잘 맞는지
- [ ] 처음부터 안 써도 되는 이유

## 이 문서에서 특히 다루고 싶은 것

- [ ] 제출용 형식 정리에 LaTeX가 유리한 이유
- [ ] 수식, 참고문헌, 그림 번호 관리가 편한 이유
- [ ] 초고는 다른 도구로 쓰고 나중에 옮기는 흐름
- [ ] 프로젝트 예시를 기반으로 실제 도입 방법 설명

## 이 저장소의 예시

현재 예시 프로젝트에는 `thesis-example/latex/main.tex`가 들어 있다.
