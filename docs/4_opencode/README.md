# OpenCode CLI

이 문서는 OpenCode의 세부 명령을 모두 설명하기보다, 왜 이 도구가 필요한지와 초급 사용자가 어떤 방식으로 작업을 맡길 수 있는지 설명하는 데 초점을 둔다.

## 한 줄 요약

**OpenCode는 채팅 한 번으로 끝나지 않는 파일 수정, 문서 정리, Git 작업을 실제 작업 공간에서 이어서 처리하게 해주는 도구다.**

## 이 폴더에서 다루는 방향

- 기능 전달보다 왜 OpenCode를 쓰는지 설명
- 단순 질문보다 실제 작업 위임 도구라는 점 설명
- 초급 사용자가 바로 이해할 수 있는 사용 구조 중심

## 먼저 다루면 좋은 것

- [ ] Cursor 채팅과 OpenCode의 차이
- [ ] 왜 터미널 기반 작업 도구가 필요한지
- [ ] 여러 파일 수정이나 Git 작업에 강한 이유
- [ ] 세션을 이어가며 작업하는 장점
- [ ] 작업 규칙 파일을 두고 쓰는 이유

## 이 문서에서 특히 다루고 싶은 것

- [ ] `opencode.json` 같은 설정 파일이 왜 필요한지
- [ ] `/agent` 같은 명령을 왜 쓰는지
- [ ] 반복 작업을 짧은 명령으로 부르는 방법
- [ ] 프로젝트 규칙을 미리 적어두면 어떤 점이 편해지는지
