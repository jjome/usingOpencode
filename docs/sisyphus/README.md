# Sisyphus — AI 에이전트 시스템

OpenCode 안에서 동작하는 에이전트. 단순 질답을 넘어, 조사·분석·작성을 위임할 수 있다.

## 논문 작성에서 어떻게 쓰이나?

- **자료 조사**: 관련 논문/자료를 찾아 요약해달라고 위임
- **구조 상담**: 논문 전체 구조나 논증 흐름에 대해 고급 상담
- **반복 작업 자동화**: 참고문헌 정리, 형식 통일 등

## 다룰 주제

- [ ] Sisyphus란 무엇인가 (에이전트 개념 소개)
- [ ] 서브에이전트 역할 이해
  - [ ] Explore — 내 프로젝트 안에서 내용 찾기
  - [ ] Librarian — 외부 자료 검색 & 문서 조회
  - [ ] Oracle — 깊은 사고가 필요한 상담 (논문 구조, 논증 검토)
  - [ ] Metis — 작업 전 분석 (무엇을 해야 하는지 정리)
- [ ] Task 위임하기 — 구체적으로 요청하는 법
- [ ] 병렬 작업 — 여러 조사를 동시에 시키기
- [ ] 결과 검증 — AI 결과물을 비판적으로 확인하는 습관
