# Claude — 왜 쓰고 어떻게 붙이는가

이 문서는 Claude의 답변 예시를 많이 모으는 것이 아니라, 초급 사용자가 Claude를 왜 써야 하는지와 작업 환경에 어떻게 붙여서 쓰는지를 설명하는 데 초점을 둔다.

## 한 줄 요약

**Claude는 논문 작업에서 초안 작성, 정리, 검토를 도와주는 기본 AI 모델이며, 중요한 것은 답변 기술보다 어떤 맥락을 주고 어떤 환경에서 쓰는지다.**

## 이 폴더에서 다루는 방향

- 프롬프트 기교보다 Claude를 왜 쓰는지 설명
- 단일 질문 예시보다 논문 작업에서 주는 도움 설명
- 초급 사용자가 실제 작업 환경에 붙이는 방법 중심

## 먼저 다루면 좋은 것

- [ ] Claude가 논문 작업에서 도움이 되는 이유
- [ ] Claude 단독 사용과 Cursor/OpenCode 안에서 쓰는 차이
- [ ] 어떤 종류의 작업에 강한지
- [ ] 어떤 종류의 작업은 사람이 직접 검토해야 하는지
- [ ] Claude 관련 설정 파일이나 문서가 왜 필요한지

## 이 문서에서 특히 다루고 싶은 것

- [ ] `claude.md` 같은 파일을 왜 두는지
- [ ] Claude에게 논문의 배경, 톤, 규칙을 미리 알려두는 방법
- [ ] 매번 반복 설명하지 않기 위해 작업 규칙을 문서화하는 방법
- [ ] Claude를 쓸 때 기대하면 좋은 점과 기대하면 안 되는 점
