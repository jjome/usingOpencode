# Claude — AI 모델 활용법

이 모든 도구의 핵심에 있는 AI 모델. 좋은 결과를 얻으려면 좋은 질문(프롬프트)을 해야 한다.

## 다룰 주제

### 기초: AI에게 질문하는 법
- [ ] 좋은 프롬프트 vs 나쁜 프롬프트 (예시 비교)
- [ ] 역할 부여하기 ("너는 학술 논문 편집자야")
- [ ] 맥락 제공의 중요성 (배경, 분야, 목적 전달)
- [ ] 단계적으로 요청하기 (한 번에 다 vs 나눠서)

### 논문 작성에 활용
- [ ] 선행 연구 요약 요청
- [ ] 논문 구조(서론-본론-결론) 잡기
- [ ] 문장 다듬기 & 학술적 톤 전환
- [ ] 영어 논문 작성 & 번역 보조
- [ ] 참고문헌 형식 정리

### 주의사항
- [ ] AI 환각(hallucination) — 없는 논문을 지어내는 문제
- [ ] 표절 & 학술 윤리
- [ ] AI 결과물의 검증 방법
- [ ] 인용 시 AI 사용 명시 기준
