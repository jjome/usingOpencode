# OpenCode CLI

Cursor 터미널에서 실행하는 AI 명령줄 도구. Sisyphus 에이전트를 통해 복잡한 작업을 자동화할 수 있다.

## Cursor Chat과 뭐가 다른가?

- Cursor Chat: 간단한 질문, 문장 수정 등 빠른 상호작용
- OpenCode: 여러 파일에 걸친 작업, 자료 조사, 에이전트 위임 등 복잡한 작업

## 다룰 주제

- [ ] 설치 & 초기 설정
- [ ] 기본 사용법 (질문하기, 파일 편집 요청)
- [ ] 설정 파일 (`opencode.json`) 이해
- [ ] Slash 명령어 (`/init-deep`, `/handoff` 등)
- [ ] Session — 대화 맥락 유지 & 이어서 작업하기
- [ ] MCP 서버 — 외부 도구 연동 (웹 검색, 문서 조회 등)
