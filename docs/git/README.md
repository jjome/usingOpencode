# Git — 논문 버전 관리

논문 원고를 Git으로 관리하는 방법을 다룬다. 코드가 아닌 **글**을 위한 Git 사용법에 초점을 맞춘다.

## 왜 논문에 Git을 쓰는가?

- "최종", "진짜최종", "최종_수정본" 파일 난립 방지
- 언제, 무엇을 고쳤는지 이력이 남는다
- 지도교수 피드백 반영 전후를 비교할 수 있다
- 잘못 고쳤을 때 이전 버전으로 되돌릴 수 있다

## 다룰 주제

- [ ] Git이란 무엇인가 (비개발자를 위한 설명)
- [ ] 설치 & 초기 설정
- [ ] 기본 명령어 (`init`, `add`, `commit`, `log`, `diff`)
- [ ] 커밋 메시지 잘 쓰는 법 (논문 맥락)
- [ ] 되돌리기 (`checkout`, `revert`)
- [ ] 브랜치 기초 (초고 vs 수정본 분리)
- [ ] GitHub 연동 (백업 & 지도교수 공유)
- [ ] `.gitignore` — 추적하지 않을 파일 설정
