# Cursor — AI 작업 환경으로 쓰기

이 문서는 Cursor 기능을 하나씩 나열하기보다, 왜 Cursor가 초급 사용자에게 좋은 작업 환경인지와 논문 작업에서 어떤 장점을 주는지 설명하는 데 목적이 있다.

## 한 줄 요약

**Cursor는 글을 쓰는 곳과 AI를 쓰는 곳이 분리되지 않아서, 논문 초안 작성과 수정, 파일 관리 흐름을 한 자리에서 이어가기 쉬운 도구다.**

## 이 폴더에서 다루는 방향

- 기능 목록보다 작업 환경으로서의 장점 설명
- 채팅 사용법보다 왜 편집기 안에서 AI를 쓰는지가 중요한지 설명
- 초급 사용자가 처음 깔고 적응하는 흐름 중심

## 먼저 다루면 좋은 것

- [ ] 왜 브라우저 대신 Cursor에서 작업하면 편한지
- [ ] 논문 파일을 한 폴더에서 관리하는 장점
- [ ] AI 채팅, 파일 편집, 터미널을 한 곳에서 쓰는 장점
- [ ] Git과 함께 쓸 때 편한 점
- [ ] OpenCode를 함께 붙여 쓰는 흐름

## 이 문서에서 특히 다루고 싶은 것

- [ ] Cursor를 논문 작업 기본 환경으로 쓰는 이유
- [ ] 프로젝트 폴더를 열고 작업하는 감각
- [ ] AI에게 파일 맥락을 보여주기 쉬운 이유
- [ ] Git, OpenCode, Claude 기반 작업을 한 자리에서 묶는 방법
