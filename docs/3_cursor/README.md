# Cursor — AI 편집기

논문 작성에 Cursor를 활용하는 방법을 다룬다. 코드 에디터지만, AI 기능 덕분에 글쓰기 도구로도 강력하다.

## 왜 Cursor를 쓰는가?

- AI가 편집기 안에 내장되어 있어 별도 창 전환 없이 바로 질문/수정 가능
- Markdown으로 논문을 쓰면 Git 버전 관리와 궁합이 좋다
- 터미널에서 OpenCode를 바로 실행할 수 있다
