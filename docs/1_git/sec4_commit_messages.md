# 커밋 메시지

> 중요도: ⭐⭐ — 직접 잘 쓰려고 너무 신경 쓰지 않아도 된다.

## 핵심

커밋 메시지는 "이번에 무엇을 저장했는지" 적는 짧은 메모다.

하지만 이 가이드에서는 사용자가 커밋 메시지를 잘 쓰는 법까지 익히는 것을 목표로 하지 않는다.

## 그냥 이렇게 하면 된다

커밋할 때는 에이전트에게 맡기면 된다.

- "변경 내용 보고 커밋 메시지 만들어줘"
- "적절한 메시지로 커밋해줘"

대부분의 경우 이 정도면 충분하다.

## 이것만 기억하면 된다

- 메시지는 너무 복잡할 필요 없다
- 무엇을 했는지만 보이면 된다
- 잘 모르겠으면 에이전트에게 맡기면 된다
