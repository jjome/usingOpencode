# Git — 논문 버전 관리

논문 원고를 Git으로 관리하는 방법을 다룬다. 명령어를 깊게 익히기보다, 흐름을 이해하고 실제 작업은 에이전트와 함께 진행하는 방식에 초점을 맞춘다.

## 왜 논문에 Git을 쓰는가?

- "최종", "진짜최종", "최종_수정본" 파일 난립 방지
- 언제, 무엇을 고쳤는지 이력이 남는다
- 지도교수 피드백 반영 전후를 비교할 수 있다
- 잘못 고쳤을 때 이전 버전으로 되돌릴 수 있다
