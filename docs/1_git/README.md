# Git — 논문 버전 관리

논문 원고를 Git으로 관리하는 방법을 다룬다. 이 문서의 목적은 Git을 깊게 설명하는 것이 아니라, 초급 사용자가 실제로 안전하게 쓰기 시작하도록 돕는 것이다.

## 한 줄 요약

**Git은 논문 파일을 계속 같은 곳에서 작업하면서, 변경 기록과 백업을 남기기 위한 도구다.**

## 이 폴더는 어떻게 보면 되나?

처음에는 개념을 깊게 이해하려고 하지 않아도 된다.

- 먼저 실제 사용 흐름을 익힌다
- 바로 써보면서 필요한 것만 추가로 본다
- 자세한 개념은 막히거나 궁금할 때만 확인한다
