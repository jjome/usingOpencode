# 되돌리기

> 중요도: ⭐⭐ — 직접 해결하려고 무리하지 말고, 에이전트에게 상황을 설명하면 된다.

## 핵심

Git은 되돌리기 기능이 강한 도구다.

무언가 잘못됐더라도, 바로 손으로 해결하려고 하기보다 에이전트에게 맡기는 편이 더 안전하다.

## 그냥 이렇게 하면 된다

에이전트에게 이렇게 말하면 된다.

- "방금 한 변경을 되돌리고 싶어"
- "이 파일을 이전 상태로 돌리고 싶어"
- "최근 커밋을 취소하고 싶어"
- "지금 상태를 보고 가장 안전한 되돌리기 방법을 알려줘"

## 이것만 기억하면 된다

- 혼자 급하게 되돌리려 하지 않아도 된다
- 먼저 에이전트에게 상황을 설명한다
- Git은 보통 생각보다 되돌릴 수 있는 범위가 넓다
