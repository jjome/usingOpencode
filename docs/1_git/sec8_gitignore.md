# .gitignore

> 중요도: ⭐ — 처음에 한 번 정리해두면 이후에는 거의 신경 쓸 일이 없다.

## .gitignore는 무엇인가?

아주 간단히 말하면, **Git이 굳이 기억하지 않아도 되는 파일을 빼두는 목록**이다.

예를 들면:

- 자동으로 생기는 파일
- 임시 파일
- 빌드 결과물
- 에디터 설정 파일

이런 것들은 보통 논문 원고 자체가 아니기 때문에, Git에서 빼두는 편이 깔끔하다.

## 에이전트와 함께 쓸 때

실제로는 이렇게 맡기면 된다.

- "논문 프로젝트용 `.gitignore` 만들어줘"
- "지금 폴더에서 Git이 굳이 추적하지 않아도 되는 파일 정리해줘"
- "LaTeX/Markdown 작업에 맞는 `.gitignore` 넣어줘"

사용자는 `.gitignore`를 세세하게 외우기보다, **불필요한 파일을 Git에서 빼두는 설정** 정도로만 받아들이면 충분하다.

## 이것만 기억하면 된다

- `.gitignore`는 불필요한 파일을 제외하는 목록이다
- 보통 프로젝트 시작할 때 한 번 만든다
- 실제 내용은 에이전트에게 맡겨도 된다

## 필요할 때 찾아보는 내용

### 논문 프로젝트용 예시

```gitignore
# OS 자동 생성 파일
.DS_Store
Thumbs.db

# 편집기 설정
.vscode/
.idea/

# 빌드 결과물
*.pdf
output/

# 임시 파일
*.tmp
*.bak
*~

# OpenCode 작업 파일
.opencode/
```

### 기억할 점

- `*.pdf`를 Git으로 관리하고 싶다면 그 줄은 지우면 된다
- 이미 Git이 추적 중인 파일은 `.gitignore`에 넣어도 바로 사라지지 않는다

지금은 자세히 외우기보다, 필요할 때 다시 찾아보는 정도면 충분하다.
