# 설치와 초기화

> 중요도: ⭐

처음에는 조금 헷갈릴 수 있지만, 사실 이 단계는 한 번만 해두면 거의 끝난다. 여기서는 아주 가볍게만 본다.

## 한 줄 요약

**설치는 Git 프로그램을 넣는 것이고, 초기화는 내 폴더를 Git으로 관리하기 시작하는 것이다.**

## 어떻게 생각하면 되나?

Git을 쓰려면 먼저 컴퓨터에 Git이 있어야 한다.

그다음 내가 작업할 논문 폴더에 "이 폴더는 이제 Git으로 관리할게"라고 시작해주면 된다.

## 그냥 이렇게 쓰면 된다

순서는 이 정도면 충분하다.

1. Git을 설치한다
2. 이름과 이메일을 한 번 설정한다
3. 논문 폴더에서 `git init`을 한다

Windows는 [git-scm.com](https://git-scm.com/download/win)에서 설치하면 된다.

macOS는 보통 아래 명령으로 설치한다.

```bash
xcode-select --install
```

설치가 끝나면 확인한다.

```bash
git --version
```

그다음 사용자 정보를 한 번 설정한다.

```bash
git config --global user.name "홍길동"
git config --global user.email "hong@university.ac.kr"
```

마지막으로 논문 폴더에서 Git 관리를 시작한다.

```bash
git init
```

## 이것만 기억하면 된다

1. 설치는 컴퓨터에 Git을 넣는 것이다
2. 사용자 정보 설정은 한 번만 하면 된다
3. 초기화는 내 폴더를 Git 저장소로 만드는 것이다
4. 보통 이 단계는 프로젝트 처음에 한 번만 한다

## 고급 과정

초급 단계에서는 그냥 설치하고 `git init`만 해도 충분하다. 하지만 조금 더 이해하면 설치와 초기화가 서로 다른 층위의 작업이라는 점이 보인다.

### 1. 설치와 초기화는 왜 다른가?

설치는 프로그램을 운영체제에 넣는 작업이다.

초기화는 특정 폴더 안에 Git 저장소를 만드는 작업이다.

즉:

- 설치: 내 컴퓨터가 Git 명령을 사용할 수 있게 만드는 것
- 초기화: 지금 이 폴더를 Git이 추적하도록 시작하는 것

그래서 Git을 한 번 설치해두면, 여러 프로젝트 폴더에서 각각 `git init`을 할 수 있다.

### 2. `git init`을 하면 무슨 일이 생기나?

`git init`을 실행하면 폴더 안에 `.git/` 디렉터리가 생긴다.

이 안에는 Git이 사용하는 핵심 정보가 들어 있다.

- 커밋 기록
- 브랜치 정보
- 설정 일부
- Git 내부 객체와 참조 정보

즉, 눈에 보이는 작업 파일은 그대로 두고, Git은 `.git/` 안에서 그 역사를 관리하기 시작한다.

### 3. 사용자 이름과 이메일은 왜 필요한가?

Git은 커밋을 남길 때 누가 그 작업을 했는지 함께 기록한다.

그래서 `user.name`과 `user.email`을 설정해두면 각 커밋에 작성자 정보가 남는다.

이 정보는 협업할 때 특히 중요하지만, 혼자 작업해도 나중에 기록을 볼 때 도움이 된다.

### 4. `--global`은 무슨 뜻인가?

```bash
git config --global user.name "홍길동"
```

여기서 `--global`은 이 설정을 현재 컴퓨터 사용자 기준으로 넓게 적용하겠다는 뜻이다.

즉, 새 프로젝트를 만들 때마다 이름과 이메일을 매번 다시 넣지 않아도 된다.

### 5. 언제 다시 손대야 하나?

보통은 이 단계에 다시 손댈 일이 많지 않다. 다만 이런 경우에는 다시 확인할 수 있다.

- 새 컴퓨터로 옮겼을 때
- GitHub 계정을 바꿨을 때
- 이름이나 이메일을 잘못 넣었을 때
- 프로젝트 폴더에서 아직 `git init`을 안 했을 때
