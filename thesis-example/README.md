# Thesis Example

이 폴더는 문서 설명용 샘플이면서, 사용자가 실제 논문 작업을 시작할 때 베이스로 삼을 수 있는 예시 프로젝트다.

## 이 폴더의 목적

- 논문 작성용 기본 폴더 구조를 보여준다
- Git 실습 예시를 이 폴더 기준으로 설명한다
- Markdown 초고, 참고문헌, LaTeX 파일을 함께 관리하는 흐름을 보여준다

## 가정한 주제

AI 도구를 활용한 논문 작성 워크플로우 정리.

## 폴더 구조

```
thesis-example/
├── outline.md
├── chapters/
├── references/
└── latex/
```

문서에서는 이 폴더를 실제 연구자가 작업하는 논문 저장소처럼 다룬다. 필요하면 이 폴더를 복사해서 자신의 논문 프로젝트 시작점으로 써도 된다.
